## ?? Troubleshooting

### **Site Not Loading?**

1. **Check Actions tab** for deployment status
2. **Wait 2-3 minutes** after enabling Pages
3. **Clear browser cache** (Ctrl+F5)
4. **Try incognito mode**

### **404 Error?**

1. Verify Pages is enabled (Settings ? Pages)
2. Check branch is set to `main`
3. Check folder is set to `/` (root)
4. Verify files exist in repository root

### **Still Not Working?**

1. Check repository visibility (must be Public for free Pages)
2. Verify GitHub Pages is enabled for your account
3. Check Actions tab for error messages
