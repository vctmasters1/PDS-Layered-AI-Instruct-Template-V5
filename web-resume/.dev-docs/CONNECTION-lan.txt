## TLS Certificate

- **Type**: Self-signed
- **Location**: `ResumeServer/certs/cert.pem`, `certs/key.pem`
- **Validity**: 365 days from generation
- **Browser Warning**: Normal behavior on first visit
  - Click "Advanced"
  - Click "Proceed to 192.168.1.80 (unsafe)"
  - Warning appears because cert is self-signed (not publicly trusted)

## Access Control

### LAN Only
- Only accessible from machines on your home network (192.168.1.x)
- Default: Caddy reverse proxy handles all access

### External Access (Optional)
To allow external access with limited distribution:

1. **Port Forward on Router**
   ```
   External 443 → 192.168.1.80:443
   External 80  → 192.168.1.80:80  (HTTP redirect)
   ```

2. **Firewall Configuration**
   - Windows Firewall: Allow TCP ports 80, 443
   - Router firewall: Open inbound 80, 443

3. **Share Public IP**
   - Find your public IP: https://whatismyipaddress.com
   - Share as: `https://<public-ip>`
   - Note: Show someone this URL directly (not over email/chat for security)
   - Disclaimer: URL will have cert warning (expected for self-signed)

## Connection Details for Sharing

When sharing with others:

1. **Via LAN** (best for WiFi guests):
   - URL: `https://192.168.1.80`
   - They connect to your WiFi
   - No external port forwarding needed
   - Fast, local network access

2. **Via External IP** (remote access):
   - URL: `https://<your-public-ip>`
   - Requires router port forwarding (443 → 192.168.1.80:443)
   - Share IP address directly (not via email/messaging)
   - Security note: Limited to trusted people only
   - Warning: Self-signed cert will show security warning

## Troubleshooting

**Certificate not trusted even after accepting warning**
```bash
# Regenerate certificate
rm ResumeServer/certs/*
./start-dev-modes.ps1 -Mode lan
```

**Caddy not reverse proxying**
```bash
# Check Caddy status
docker compose ps caddy

# Check Caddyfile
cat ResumeServer/.caddyfiles/lan-selfsigned.Caddyfile

# Restart Caddy
docker compose restart caddy
```

**External access not working**
- Verify ports 80/443 forwarded in router admin
- Check Windows Firewall: allow ports 80, 443
- Verify Caddy is running: `docker compose logs caddy`
- Test from outside network

**Can't connect from LAN**
```bash
# Verify LAN IP is correct
ipconfig | grep "IPv4 Address"

# Verify Caddy listening
netstat -ano | findstr :443
```

## Switching Modes

**From Local → LAN**
```powershell
./start-dev-modes.ps1 -Mode lan
# Generates self-signed cert, starts full Docker stack
```

**From LAN → Production**
- Update .env with DDNS_DOMAIN, DYNU_TOKEN, POSTGRES_PASSWORD
- Port forward 80+443 on router
- Run: `./start-dev-modes.ps1 -Mode production`
