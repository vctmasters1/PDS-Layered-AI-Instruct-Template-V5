# .AI-Instruct.md (Aeroponic Controller)

> **Parent**: `devices/.AI-Instruct.md`

## Device Overview

The **Aeroponic Controller** manages an aeroponic growing system — a soilless cultivation method where plant roots are suspended in air and periodically misted with nutrient-rich water.

## Platform

- **Web application** served at `marketplace.pipedreamsystems.com/device/aero-ctrl/<serial>`
- Device access via QR code scan → browser-based config UI
- Designed for future wrapping in a native app shell (e.g., Capacitor/PWA) if needed

## Communication Paths

| Path | Protocol | Purpose |
|---|---|---|
| Browser ↔ Server | **HTTPS** (TLS 1.2+) | Save/load configs, user auth, firmware metadata, device registry |
| Browser/Phone ↔ Device | **BLE** (Web Bluetooth API) | Direct local config writes, provisioning, Wi-Fi setup (future) |
| Device → Server | **HTTP polling** | Telemetry push, `GET /pending-sync`, OTA download, ACK |

- The device polls `GET /v1/devices/:id/pending-sync` every ~2.5 min using `X-Device-Token` auth.
- OTA is **cloud-dispatched**: HMI API queues `pendingOtaUrl` → device downloads via `GET /v1/firmware/:deviceType/:version/device-download` proxy → ACKs via `POST /v1/devices/:id/ota/ack`.
- NVS credentials (`api_url`, `device_id`, `device_token`) are flashed at manufacturing via `nvs_devrig.csv`.
- BLE is planned for local provisioning and direct config writes (not yet implemented).

## What This Device Does

- Controls misting cycles (interval and duration) for root zone nutrient delivery
- Manages 4 nutrient/chemical dosing pumps with N-P-K tracking per pump
- Manages fill and discharge water pumps with configurable water change scheduling
- Controls grow light scheduling with multiple on/off periods per day
- Monitors and targets pH range of the nutrient solution (with hysteresis)
- Supports preset crop templates for quick configuration

## User Interface Description

- **Crop Template Dropdown** — preloaded presets (e.g., catnip, tomatoes, flowers, lettuce, marijuana-veg, marijuana-flower). Selecting a template populates the form with defaults for that crop.
- **Light Schedule** — on/off times (time of day), with ability to add multiple light periods per day.
- **pH Control** — target pH setting, with hysteresis as an advanced option.
- **Misting Cycle** — on/off toggle with interval and duration controls.
- **Nutrient Pumps (×4)** — each pump has:
  - Fertilizer/nutrient product dropdown (determines that product's N-P-K ratio)
  - Dosing rate / concentration
  - The familiar N-P-K (xx-xx-xx) display per pump, with inferred PPM per element
  - PPM calculations must factor across all active pumps to show aggregate N-P-K / PPM
- **Water Change Schedule** — configurable by time interval OR by volume of water added. Volume-based scheduling allows inference of change frequency relative to plant growth stage (young/small plants consume less water → less frequent changes).
- **Actions:**
  - Save settings (persist to server)
  - Write to device (push config to the physical device)
  - Provision to network (Wi-Fi setup)
  - Set device password
  - Firmware update notification and OTA actions
