# .AI-Instruct.md (Device Template)

> **Parent**: `devices/.AI-Instruct.md`

This is the **reference template** for creating new device handlers. It is not a real device — do not register it.

## Purpose

Provides a copy-ready scaffold so every new device handler follows a consistent structure. All files contain `TODO` placeholders and example parameters that must be replaced.

## Files

| File | Purpose |
|---|---|
| `index.ts` | Handler implementation — replace `TODO_DEVICE_TYPE` and `TODO_DISPLAY_NAME`, set protocols |
| `config-schema.ts` | Config parameters — replace example params with real device-specific parameters |
| `firmware-versions.ts` | Firmware version list — add real versions with changelog, binary size, SHA-256 |
| `routines.ts` | Protocol routines — implement only if the device uses BLE or other binary protocols |

## How to Use

```powershell
Copy-Item -Recurse devices-hmi/api/src/devices/_template devices-hmi/api/src/devices/<device-type>
```

Then follow the 9-step checklist in `devices/.AI-Instruct.md`.
