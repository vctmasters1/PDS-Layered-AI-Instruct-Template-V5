# .AI-Instruct.md (Portioning Feeder)

> **Parent**: `devices/.AI-Instruct.md`

## Device Overview

The **Portioning Feeder** is an automated food dispensing device that delivers measured portions on a configurable schedule. Designed for pet feeding, livestock, or any application requiring timed, metered dispensing.

## What This Device Does

- Dispenses a configurable weight of food per feeding
- Runs on an automatic schedule (configurable feedings per day)
- Controls motor speed during dispensing
- Monitors food level and alerts when supply is low

## Communication Paths

| Path | Protocol | Purpose |
|---|---|---|
| Browser ↔ Server | **HTTPS** (TLS 1.2+) | Save/load configs, user auth, firmware metadata, device registry |
| Browser/Phone ↔ Device | **BLE** (Web Bluetooth API) | Direct local config writes, provisioning, Wi-Fi setup, firmware OTA |

## Configurable Parameters (v1.0.0)

| Parameter | Type | Range/Options | Default | Description |
|---|---|---|---|---|
| `portionSizeGrams` | range | 1–500 | 50 | Weight of each portion (grams) |
| `feedingsPerDay` | range | 1–12 | 2 | Number of scheduled feedings per day |
| `scheduleEnabled` | boolean | — | true | Enable automatic scheduled dispensing |
| `dispensingSpeed` | enum | slow, normal, fast | normal | Motor speed during dispensing |
| `lowFoodAlert` | boolean | — | true | Alert when food level is low |
| `lowFoodThresholdPercent` | range | 5–50 | 15 | Percentage remaining to trigger alert |
